# Rodar localmente 🖥️

### 1. Clone o repositório
```
bash | git clone [https://github.com/enzocostapaz/teste-front-end.git](https://github.com/enzocostapaz/teste-front-end.git)
```
### 2. Entre na pasta do projeto
```
cd teste-front-end
```

### 3. Instale as dependências
```
npm install
```

### 4. Execute o servidor de desenvolvimento
```
npm run dev
```
#
# Compilar 📦
### Execute a build
```
npm run build
```
